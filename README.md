回到正题来，我们做了以下这些功能
## PPT模式
单击戒指的按钮下一页ppt，双击上一页
## 媒体模式
单击在播放和暂停间切换，双击下一首
## 指尖实验室
将你的戒指放在任何地方，开启该模式后，可实时显示物体的3轴加速度，陀螺仪数据，如有需求，可以导出为csv文件
## 水平仪
把戒指放在任何地方，你就可以知道他的倾斜角度，我们还做了**3D建模**直观显示
## 轨迹绘制（Beta）
戒指会记录你指尖的滑动轨迹，并投射到虚拟布上作画
## 手语识别（Beta）
在我们构思功能的时候，我们就在想可不可以弄一点**科技向善**的功能，所以我们做了这个，你的戒指可以是**实时手语翻译器**！一般而言，一个字对应一个动作，App会识别用户的动作，把他转换为手语候选词列表，并提交给文本大模型，大模型精心语义理解，把这些候选词连成句子，返回给用户，这样我们就**能看懂手语**啦
## 手势快捷键映射
将手势与快捷键绑定，解放双手!
## 命令方块
谁不想要一个使唤ai的命令方块呢？我们做了！（该模式由Coding模式和手势快捷键映射模式共同组成）
